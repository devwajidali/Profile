# Personal Portfolio Website

## 📌 Project Overview

This is my **Personal Portfolio Website** built using **HTML5** and **CSS3**. The website showcases my skills, projects, education, and contact information. It serves as my online portfolio where visitors can learn more about me and explore the projects I have created.

The main goal of this project was to practice front-end web development while building a professional portfolio for my developer journey.

---

## 🚀 Features

* Modern and responsive design
* Clean and user-friendly interface
* Responsive navigation bar
* Hero/Home section
* About Me section
* Skills section
* Projects showcase
* Contact section
* Professional footer
* Smooth scrolling navigation
* Mobile-friendly layout
